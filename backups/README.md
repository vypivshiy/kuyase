# Папка для пользовательских дампов прошивок (`backups/`)

>[!warning]
> **Дампы прошивок не входят в репозиторий `KUYASE`** (по соображениям авторского права и размера образов).

Чтобы собрать и запустить виртуальную колонку, получите дамп одним из двух способов:

1. **Снимите дамп со своей собственной колонки по сетевому ADB (`<IP>:5555`)**:
   ```bash
   # Linux / macOS / WSL:
   ./scripts/dump-from-adb.sh 10.1.1.56
   ```
   ```powershell
   # Windows PowerShell:
   .\scripts\dump-from-adb.ps1 10.1.1.56
   ```
   Скрипт автоматически сохранит чистый системный архив `rootfs.tar.gz` (без раздела `/data` и без ваших токенов/паролей Wi-Fi) в папку `backups/dump-<модель>-<дата>/`. Подробности и ручные команды — в [`../DUMP_GUIDE.md`](../DUMP_GUIDE.md).

2. **Возьмите готовый дамп на профильных тематических ресурсах** (форум 4PDA, профильные Telegram-сообщества исследователей умных колонок) и положите папку или файл дампа сюда в `backups/`.
   Поддерживаются любые распространённые форматы дампов системного раздела:
   * Архив корневой ФС: **`rootfs.tar.gz`** / **`*.tgz`**;
   * Образ тома UBIFS или раздела NAND UBI: **`ubi0_0_rootfs.img`**, **`mtd3_system.bin`**, **`*.ubi`**, **`*.ubifs`**;
   * Образ раздела eMMC (`ext4`): **`system.img`** или **`system.img.gz`**.

После помещения дампа в `backups/` просто запустите:
```bash
# Linux / WSL (только сборка образа или сборка + запуск):
sudo ./scripts/prepare-rootfs.sh
./scripts/run-qemu.sh
```
```powershell
# Windows PowerShell:
.\scripts\run-qemu.ps1
```
Скрипт сам найдёт дамп в `backups/`, определит модель колонки из `/system/vendor/quasar/quasar.cfg`, соберёт загрузочный образ `work/<board>-system.ext4` и запустит эмулятор.
